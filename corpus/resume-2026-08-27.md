## How the run is being executed

Master-orchestrator mode from `plan-split-dispatch`: one fresh subagent per
brief, curated context, no inherited conversation history. The controller plans,
dispatches, verifies and integrates; it does not write the code.

**The rule that matters most: no completion claim without fresh verification.**
After every wave the controller itself runs `npm run build`, `npm test`,
`npm run lint`, `bash corpus/lint.sh`, plus `git check-ignore` on every new
source directory — then commits. Twice now that last check would have been the
only thing standing between a silent failure and a green-looking commit.

Each dispatch prompt carries: the brief, the working directory and branch, the
**verbatim contracts** from briefs it depends on, an explicit Skip list, the repo
conventions that bear on that chunk, the gate commands with the current baseline
test count, and a required **Handoff for dependents** section. The handoffs are
the connective tissue — dependent briefs are only as accurate as the contracts
threaded into them.

## Rulings — decisions a fresh controller would otherwise re-litigate

- **[wave order]** Re-derived from file ownership, not just dependencies. See above.
- **[brief 51]** `EditPanel.tsx` kept calling the deleted `/api/slide-ai` on purpose — it was on 51's must-NOT-touch list, and removing it properly means deciding what cross-family variant switching does without an AI remap. Brief 59 owns that.
- **[brief 53]** `markup.md` said props take "a value from a named scale or a short enum", which cannot express `<Image src="...">`. Accepted splitting into **scale props** (`size`/`align`/`emphasis`, still the only enums) and **content props** (`Image.src` required, `Image.alt`, `Quote.by`, `Stat.label`). The invariant that matters — no prop carries a style value, no `style` or `class` anywhere — holds and has a test.
- **[brief 54]** Two compile paths on purpose: `compileDocument` strict for the render pipeline, `compile`/`compileSource` forgiving for the live preview, because a document is broken most of the time while you type it.
- **[brief 54]** The compile is browser-safe. That is load-bearing: it is what lets brief 59 preview without a second copy of style resolution, and why `api/src/routes/preview.ts` was deleted rather than rebuilt.
- **[brief 55]** Login lockout keyed on **address, never username** — with exactly one account, a username-keyed lockout lets any stranger lock the owner out permanently. And `429` immediately rather than an artificial delay, because holding a connection open is the DoS the measure exists to prevent.
- **[brief 56]** `/uploads/*` is public by necessity — headless Chromium carries no session cookie. A real trade, recorded with its reasoning; the first thing to revisit if this ever leaves loopback.
- **[brief 60]** "Start a post from this article" was withdrawn at dispatch rather than built. Genuinely undecided; brief 59 owns the editor and therefore the answer.
- **[routing error, mine]** Brief 54's type-collision finding was routed to brief 61 as a theme gap. It is half a theme gap and half a code one — `WZD_TYPOGRAPHY_SCALES` maps two adjacent sizes to one token. Brief 65 fixes both halves.

## Two live defects, both filed

**`size="xl"` is currently a no-op on `Heading`.** `WZD_TYPOGRAPHY_SCALES` in
`core/src/wizard/components/style.ts` maps `Heading` `lg` and `xl` to the same

**The repo ships four themes where `decisions.md` says three.** The rename
`warm-industrial` → `warm-industrial-1` was never done; it touches ~15 call
sites, the `posts.theme` column default, and existing rows. **Brief 65** — and
note it is a data migration, which is why it is opus.

## Incidents worth not repeating

Both are in [`log.md`](log.md) in full. Both are the same shape: **green because
nothing ran.**

1. **`npm test` was destroying the developer's database.** `api/src/server.test.ts`
   had always set `NEWSPAPPER_DB_PATH`, and `defaultDbPath()` never read it —
   while the test file's own comment claimed the DB was ephemeral. Harmless until
   brief 52's destructive v2→v3 migration landed, which then wiped the dev
   database's 1 post and 33 articles on the next test run. Fixed with a
   regression test. *A harness that sets an environment variable is not evidence
   that anything reads it.*
2. **A `.gitignore` pattern nearly ate a whole module.** Brief 56 needed to ignore
   the `uploads/` store; unanchored, `uploads/` also matches `core/src/uploads/`.
   The module would have built and tested green while being invisible to git, and
   shipped as "done" until someone cloned the repo. This is why `git check-ignore`
   on every new source directory is part of the wave gate.

A third of the same family: the `ui/src/lib/types.ts` guard test that
`decisions-engineering.md` claimed existed for 2.5 months **never did**. Brief 58
wrote it, and doing so exposed that `ui/**/*.test.ts` was missing from
`vitest.config.ts`'s include — so it would have existed and never executed.
