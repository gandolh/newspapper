## The docs site

<https://gandolh.ro/newspapper/docs/> is a Starlight site built from this folder. Almost all of it is rendered from the project wiki: `scripts/sync-corpus.mjs` copies the `corpus/wiki/` pages into `src/content/docs/wiki/` (gitignored) on every build, TypeDoc writes the `@newspapper/core` reference into `public/reference/`, and `diagrams/pipeline.json` compiles to `public/diagrams/pipeline.html` through archify when it is installed (the HTML is committed, so the build works without it). The one page written by hand is `src/content/docs/index.mdx`.

```bash
npm run docs --workspace=docs    # sync, diagrams, TypeDoc, then astro build into docs/dist/
```

vps-deploy publishes `docs/dist/` to `/newspapper/docs/` together with the app. It does not build the site, so run the command above first. The base path is set in `astro.config.mjs`.
